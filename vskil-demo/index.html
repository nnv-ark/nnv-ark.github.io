VSKiL — sample files

Sample VAT summaries for reviewing VSKiL. The company and all figures are fictional.

Sample files

These are the files our invoicing app RUKK exports for VSKiL. VSKiL only imports a summary into the company whose ID number (kennitala) it carries, so first add the sample company below.

1. Add the sample company

  1. Open VSKiL → Settings… (⌘,) and choose the Companies tab.
  2. Click + and enter:
    NameSólbakki Bygg ehf.
    ID number (kennitala)4503158850
    VAT number (VSK-númer)145623
  3. Click Make active and close Settings.

2. Import a VAT summary

  1. In the main window, open Periods of the year and select Jul–Aug.
  2. Drag _vskil-4503158850-2026-32.json onto the VSKiL window — or click From RUKK…, then Choose File…, and pick the file.
  3. The period's entries appear, and the VAT return (boxes A–H) fills in: turnover, output VAT, input VAT and the amount due.
  4. Repeat with the September–October file for Sep–Oct.

3. Other features to try

  • File → New Entry… (⌘N) adds a sale or purchase by hand; the return updates at once.
  • Right-click an entry to delete it.
  • Dashboard & overview shows input and output VAT for every period of the year.
  • Settings → General → Language switches between English and Icelandic.
  • If the main window is closed, reopen it from the Window menu or by clicking VSKiL in the Dock.

Filing with Iceland Revenue

Fetch Details, Validate and File VAT Return send the return to Iceland Revenue (Skatturinn). This requires a real company's ID number and its web key (veflykill), a tax credential issued by Iceland Revenue to that company only, so it cannot be demonstrated with sample data.
